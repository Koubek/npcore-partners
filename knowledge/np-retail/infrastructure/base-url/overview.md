# Base Url in NP Retail

A minimal module providing the base URL for NP Retail's Azure Blob Storage data files. The `NPR Base Data` codeunit returns `https://npretailbasedata.blob.core.windows.net` — the root endpoint for static configuration and reference data consumed by NP Retail modules.
