# Application Area — Overview

NP Retail application area management. Enables and disables Business Central application areas (feature groups) for NP Retail modules, controlling which features are visible and available in the user interface based on licensing and configuration.

## Purpose

- Enable/disable NP Retail application areas
- Control feature visibility across NP Retail modules
- Application area registration and management
- License-driven feature gating

## Key Codeunits

| Codeunit | Purpose |
|----------|---------|
| `EnableApplicationAreas` | Core application area enablement logic |
