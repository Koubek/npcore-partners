# Description Control — Overview

Controls how item descriptions (Description 1 and Description 2) are populated on sales documents at the POS. Supports Simple (dropdown-based) and Advanced (formula-based) modes for selecting which item fields drive the line description.

**Note:** This module is **obsolete** (Removed as of 2023-06-28) — `NPR Description Control` table is no longer in use.

## Purpose

- Configurable description mapping per setup code
- Simple mode: pick from predefined sources (Item Description, Item Description 2, Variant Description, Vendor Item No.)
- Advanced mode: free-text formula for custom description construction
- Separate control for variant (var) vs standard descriptions
